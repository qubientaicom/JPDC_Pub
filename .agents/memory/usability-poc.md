---
name: 사용자 사용성 PoC
description: 사용자가 지정한 PoC 목적과 안내 기간
---

현재 구현 중인 AI 플랫폼에 대해 사용자 사용성 PoC를 진행한다. 사용자 안내 기간은 2026년 10월 30일까지 일주간이며, 시작일은 별도로 지정하지 않았다.
운영 데이터 조회의 PoC 안내 범위는 사용자가 지정한 “월별생산량, 일지정보”로 설명한다.
요일별 안내는 월요일 PoC 준비(참여 불가), 화·수요일 첨부파일 기반 질의와 RAG 사규, 목요일 MCP 비서·TAG ERP 비서·추가 제공 기본 업무용 비서, 금요일 나만의 비서 만들기이다.
테스트 범위는 누적된다: 목요일에는 화·수 일정도 테스트할 수 있고, 금요일에는 화·수와 목요일 일정도 테스트할 수 있다. 안내 팝업에는 아직 개발 중이며 대화에서 일부 오류가 발생할 수 있음을 알린다.

**Why:** 사용자가 PoC 목적과 “~ 10/30 (일주간)”, 운영 데이터 범위, 요일별 테스트 일정 및 누적 테스트 가능 범위를 명시했다.

**How to apply:** PoC 관련 안내를 수정할 때 임의로 시작일이나 정식 운영·실데이터 연동 완료를 확정하지 않는다.
