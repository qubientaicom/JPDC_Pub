---
name: 사용자 사용성 PoC
description: 사용자가 지정한 PoC 목적과 안내 기간
---

현재 구현 중인 AI 플랫폼에 대해 사용자 사용성 PoC를 진행한다. 사용자 안내 기간은 2026년 10월 30일까지 일주간이며, 시작일은 별도로 지정하지 않았다.
운영 데이터 조회의 PoC 안내 범위는 사용자가 지정한 “월별생산량, 일지정보”로 설명한다.

**Why:** 사용자가 PoC 참여 안내에 목적과 “~ 10/30 (일주간)”을 명시하고, 운영 데이터 안내를 “월별생산량, 일지정보”로 변경하도록 요청했다.

**How to apply:** PoC 관련 안내를 수정할 때 임의로 시작일이나 정식 운영·실데이터 연동 완료를 확정하지 않는다.
