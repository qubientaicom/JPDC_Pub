---
name: 첨부파일 역할
description: 사용자가 정한 대화 첨부파일의 역할 및 서식 개수 제한
---

대화화면에서 ‘지식 첨부’와 ‘서식 첨부’로 업로드 진입점을 분리하여 파일 첨부 전에 역할을 지정한다. 첨부 후 역할을 변경하지 않는다. ‘서식’은 1개 파일만 지정할 수 있다.
새 대화 시작 화면의 첨부파일에도 같은 기능을 적용한다.
파일첨부는 총 11개(지식 10개 + 서식 1개)까지 허용한다.

**Why:** 사용자는 파일 첨부 시 임베딩이 자동 시작되므로 첨부 이후 역할을 선택하면 안 된다고 설명하고, 업로드 유형을 지식과 서식으로 나누도록 요청했다.

**How to apply:** 두 화면 모두 업로드 전에 역할을 확정하고, 지식 한도 초과 파일을 서식으로 자동 지정하지 않는다. 역할 변경은 제거 후 해당 유형으로 다시 첨부한다. 삭제·전송 흐름에서도 개수 제한과 역할을 유지한다.
