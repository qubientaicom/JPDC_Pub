---
name: 첨부파일 역할
description: 사용자가 정한 대화 첨부파일의 역할 및 서식 개수 제한
---

대화화면에서 첨부파일을 ‘지식’인지 ‘서식’인지 지정할 수 있어야 한다. ‘서식’은 1개 파일만 지정할 수 있다.
새 대화 시작 화면의 첨부파일에도 같은 기능을 적용한다.
파일첨부는 총 11개(지식 10개 + 서식 1개)까지 허용한다.

**Why:** 사용자가 첨부파일 역할 선택과 서식 1개 제한을 요청했고, 새 대화 시작 화면에도 적용하도록 요청했다.

**How to apply:** 대화 첨부파일의 선택·변경·삭제·전송 흐름에서 이 제한을 유지한다.
