---
name: 비서 삭제 정책
description: 사용자가 요청한 비서 삭제의 보관 및 재사용 의미
---

‘내가 만든 모든 비서’의 삭제는 영구 제거가 아니라 삭제 상태로 보관하는 동작이다. 삭제 전 다른 사용자가 더 이상 대화할 수 없다는 안내와 함께 ‘삭제’·‘취소’로 확인을 받는다. 삭제 후 비서명 옆에 ‘삭제’를 표시하고, 수정·복제를 통한 향후 재사용 준비는 허용한다.

**Why:** 사용자가 삭제된 비서의 상태 표시와 향후 수정·복제 가능성을 명시했다.

**How to apply:** 삭제된 원본의 정보와 통계를 파괴하지 않는다. 수정이나 복제만으로 삭제된 원본을 자동 재공개하지 않는다.
