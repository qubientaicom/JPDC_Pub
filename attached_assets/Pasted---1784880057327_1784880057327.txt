# 브라우즈 화면 — "내가 만든 모든 비서" · "공개전 테스트 요청 비서" 탭 (화면 구성)

> 본 문서는 **화면에 표시되는 디자인 요소**만 기술합니다.
> 내부 동작(필터링·저장·상태 처리 등)은 별도 개발이 필요하며, 현재는 UI 레이아웃 기준입니다.

---

## 0. 공통 상단 영역 (툴바)

두 탭이 함께 사용하는 상단 영역입니다.

```
┌──────────────────────────────────────────────────────────────┐
│ [내가 만든 모든 비서] [공개전 테스트 요청 비서] [공식 비서]      │  탭
│                                                                │
│ [🔍 비서 검색…                    ]   [ + 나만의 비서 만들기 ]   │  검색 + 생성
└──────────────────────────────────────────────────────────────┘
                     (아래에 카드 그리드 영역)
```

| 요소 | 표시 내용 |
|---|---|
| 탭 버튼 | `내가 만든 모든 비서` / `공개전 테스트 요청 비서` / `공식 비서` (기본 활성: 첫 번째 탭) |
| 검색창 | placeholder `비서 검색…` |
| 생성 버튼 | `+ 나만의 비서 만들기` (강조 버튼) |
| 카드 그리드 | 선택된 탭의 비서 카드가 카드 형태로 나열되는 영역 |

- 두 탭은 **같은 카드 그리드 영역**을 공유하며, 탭에 따라 상단 안내문·빈 상태·표시 카드만 달라집니다.

---

## 1. 탭 ①  내가 만든 모든 비서

내가 만든 비서 카드가 나열되는 기본 탭입니다.

- **상단 안내 배너**: 없음
- **빈 상태 문구** (표시할 카드가 없을 때):
  ```
  아직 만든 비서가 없습니다.
  위의 + 나만의 비서 만들기로 시작해 보세요.
  ```

---

## 2. 탭 ②  공개전 테스트 요청 비서

공개 전 테스트 대상 비서를 함께 사용·평가하는 탭입니다.

- **상단 안내 배너** (카드 목록 위 배너):
  ```
  다른 사람이 공개 전 테스트를 요청한 비서입니다.
  함께 사용해 보고 평가·코멘트를 남겨 주세요.
  ```
- **빈 상태 문구**:
  ```
  아직 공개전 테스트를 요청한 비서가 없습니다.
  다른 사람이 공개 전 테스트를 요청하면 이 탭에서 함께 테스트·평가할 수 있습니다.
  ```
- **탭 표식**: 이 탭의 카드에는 `공개전 테스트` 배지가 표시됩니다.

---

## 3. 비서 카드 구성 (두 탭 공통)

```
┌────────────────────────────────────────┐
│ (아이콘)  비서 이름                       │
│           by 작성자                       │
│                                          │
│ 비서 설명 텍스트…                          │
│                                          │
│ [v1] [승인 대기] [공개전 테스트] [부서]    │  상태 배지들
│                                    💬 3   │  코멘트 칩
│ 생성 2026-07-24 · 업데이트 2026-07-24     │  날짜
│                                          │
│ [ 수정 ] [ 복제 ] [ 통계 ] [ 공식 등록 ]   │  액션 버튼
└────────────────────────────────────────┘
```

### 3-1. 카드 본문

| 영역 | 표시 내용 |
|---|---|
| 아이콘 | 업로드 이미지 또는 이름 첫 글자 |
| 제목 | 비서 이름 |
| 작성자 | `by {작성자}` (기본 `by 나`) |
| 설명 | 비서 설명 (없으면 `(설명 없음)`) |
| 코멘트 칩 | `💬 {개수}` (코멘트가 있을 때만) |
| 날짜 | `생성 … · 업데이트 …` |

### 3-2. 상태 배지

| 배지 | 의미 |
|---|---|
| `임시저장` | 작성 중인 초안 |
| `v{n}` | 버전 |
| `공식` | 공식 등록 비서 |
| `승인완료` | 공식 승인 완료 |
| `버전 갱신중` | 공식 비서 버전 갱신 중 |
| `승인 대기` | 공식 등록 심사 중 |
| `승인불가` | 공식 등록 반려 |
| `공개전 테스트` | 공개 전 테스트 대상 (② 탭 표식) |
| 공개 범위 | 비공개 / 지정자 / 부서 / 본부 / 전사 |

### 3-3. 액션 버튼

**초안(임시저장) 카드**
| 버튼 | 설명 |
|---|---|
| `이어서 작성` (강조) | 작성 중이던 내용 이어가기 |

**일반 카드**
| 버튼 | 표시 조건 |
|---|---|
| `수정` | 항상 |
| `복제` | 항상 |
| `통계` | 항상 |
| `URL 복사` | 공유 상태일 때만 |
| `공식 등록` (강조) | 아직 공식/승인 대기가 아닐 때만 |

> 카드에는 삭제·게시·테스트요청 버튼이 없습니다. 제출 액션은 `공식 등록`이 유일합니다.

| 항목 | ① 내가 만든 모든 비서 | ② 공개전 테스트 요청 비서 |

| 상단 안내 배너 | 없음 | 있음 (테스트 안내 문구) |

| 카드 · 액션 버튼 | 공통 | 공통 |
| 상단 툴바 (탭·검색·생성) | 공통 | 공통 |
