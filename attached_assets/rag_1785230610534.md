# ERP 통계정보 페이지 (Management) — UI/UX & 기능 문서

## 1. 개요 (Concept)

**ERP (통계정보)** 페이지는 사용자가 자연어로 질문을 입력하면, 시스템이 해당 질문을 **두 가지 SQL 쿼리로 해석**하여 각각의 결과를 나란히 (2분할 레이아웃) 표시하는 AI 기반 통계 조회 인터페이스입니다.

- 사용자의 질문이 모호하거나 다양하게 해석될 수 있을 때, 시스템은 두 가지 해석(해석 1, 해석 2)을 자동으로 생성합니다.
- 각 해석은 **SQL 쿼리 + 조회 결과 + 해석 문장 + 파라미터**를 포함합니다.
- 사용자는 파라미터와 해석 문장을 **직접 편집**하고 **재조회(rerun)**할 수 있습니다.

## 4. 2분할 답변 UI (Dual Response)

### 4.1 레이아웃

사용자 질문에 대해 AI가 두 가지 SQL 해석을 생성하며, 각각을 **좌우로 나란히** 배치합니다 (모바일에서는 상하 배치).

```
┌─────────────────────────┬─────────────────────────┐
│  해석 1: 인원 목록 조회   │  해석 2: 통계 집계 조회   │
│  (파란색 배경)            │  (주황/베이지 배경)        │
│                          │                          │
│  [해석 문장 편집 영역]    │  [해석 문장 편집 영역]    │
│  [재조회 버튼]            │  [재조회 버튼]            │
│                          │                          │
│  파라미터 태그 목록        │  파라미터 태그 목록        │
│  (클릭 → 인라인 편집)     │  (클릭 → 인라인 편집)     │
│                          │                          │
│  SQL 쿼리 박스            │  SQL 쿼리 박스            │
│  (어두운 배경, 초록 글자)  │  (어두운 배경, 초록 글자)  │
│                          │                          │
│  조회 결과 (마크다운 표)   │  조회 결과 (마크다운 표)   │
└─────────────────────────┴─────────────────────────┘
```

### 4.2 색상 구분

| 영역 | 해석 1 색상 | 해석 2 색상 |
|------|-----------|-----------|
| 헤더 배경 | `#f8fbff` (연파랑) | `#fff8f0` (연주황) |
| 헤더 테두리 | `#e8f0fe` | `#fef3e8` |
| 헤더 텍스트 | `#001d49` (진청) | `#493d00` (진갈색) |
| SQL 박스 | 어두운 배경 + 초록 텍스트 | 동일 |

## 5. 사용자 액션 — 해석 문장 편집

### 동작 방식
- 각 해석 패널에는 **해석 문장(description)** 이 표시됩니다.
- 텍스트 영역 옆에 **연필 아이콘 버튼** 이 있습니다.
- 연필 버튼 클릭 → 해석 문장이 **인라인 텍스트 입력 필드**로 전환됩니다.
- 편집 후 `Enter` 키 또는 **포커스 아웃(blur)** 시 자동 저장됩니다.
- 저장 후 편집 모드가 종료되고 텍스트가 업데이트됩니다.

### 상태 관리
```typescript
editingDesc: { messageId: string; interpretation: 1 | 2 } | null
editingDescValue: string
```

---

## 6. 사용자 액션 — 파라미터 편집

### 동작 방식
- 각 해석 패널에는 **파라미터 태그 목록** 이 있습니다.
  - 예: `년도: 2025`, `성별: 남`, `부서: 총무부`
- 태그를 클릭하면 해당 태그가 **인라인 입력 필드**로 변환됩니다.
- `key: value` 형식으로 편집하며, `Enter` 또는 blur 시 저장됩니다.
- 저장된 값은 해당 해석의 파라미터 배열에 업데이트됩니다.

### 상태 관리
```typescript
editingParam: { messageId: string; interpretation: 1 | 2; paramIdx: number } | null
editingValue: string
```

## 7. 사용자 액션 — 재조회 (Rerun)

### 버튼 위치
- 해석 문장 옆에 **RefreshCw 아이콘 버튼** (회색, hover 시 파란색)
- 파라미터 목록 하단에 **"재조회" 버튼** (파란색 외곽선)

### 재조회 버튼 출력 형태

```typescript
handleRerun(messageId, interpretation, params, desc?)
```

재조회 버튼을 클릭하면:

1. **새 봇 메시지 생성** (rerun-{timestamp} ID)
2. **처리 과정 아코디언 표시** (자동으로 열림)
   ```
   ✓ 1. 해석 확인 — 해석: {desc}
   ✓ 2. 파라미터 적용 — 수정된 조건으로 재조회합니다: {paramString}
   ✓ 3. SQL 생성 — 수정된 조건으로 SQL을 재생성합니다
   ✓ 4. 데이터 조회 — 데이터베이스에서 결과를 조회합니다
   ✓ 5. 결과 생성 — 조회 결과를 정리합니다
   ```
   - 각 단계 800ms 간격으로 순차 완료 표시
   - 완료 후 아코디언 자동 닫힘

3. **재조회 결과 스트리밍 출력**:
   ```markdown
   **재조회 결과**

   > **해석**: {desc}

   수정된 조건으로 조회한 결과입니다.

   | 부서 | 이름 | 직급 | 상태 |
   |------|------|------|------|
   | {부서 파라미터값} | 김철수 | 과장 | 재직 |
   | {부서 파라미터값} | 이영희 | 대리 | 재직 |
   | 보안부 | 서동혁 | 차장 | 재직 |

   **조회 조건**: {paramString}
   **조회 시간**: 0.08초
   **결과 건수**: 3건
   ```
   - 단어 단위 스트리밍 (30ms 간격)

## 8. 처리 과정 (Processing Steps) 아코디언

최초 질문 전송 시 처리 단계가 순차적으로 표시됩니다:

```
▼ 처리 과정 (접기/펼치기)
  ✓ 1. 질문 분석 — 입력된 질문을 분석하고 키워드를 추출합니다
  ✓ 2. 데이터 검색 — 관련 통계데이터를 검색합니다
  ✓ 3. 내용 분석 — 검색된 문서의 내용을 분석하고 관련성을 평가합니다
  ✓ 4. 답변 생성 — 분석 결과를 바탕으로 답변을 생성합니다
  ✓ 5. 검증 완료 — 생성된 답변의 정확성을 검증합니다
```
- 각 단계 1200ms 간격으로 완료
- 모든 단계 완료 후 아코디언 자동 닫힘

## 11. 저장 기능

  ```json

    "id": 1234567890,
    "userQuestion": "질문 텍스트",
  ```

## 15. 플로우 다이어그램

```
사용자 입력 (자연어 질문)
        │
        ▼
handleSendMessage()
        │
        ├── 사용자 메시지 추가
        ├── 채팅 히스토리 업데이트
        └── generateStreamResponse()
                │
                ├── 처리 과정 아코디언 표시 (5단계, 각 1200ms)
                ├── dualResponse 생성 (해석1 + 해석2)
                ├── 아코디언 자동 닫힘
                └── 최종 텍스트 스트리밍 출력
                        │
                        ▼
              [2분할 UI 렌더링]
              ┌──────────┬──────────┐
              │  해석 1   │  해석 2   │
              │ 파라미터 편집│파라미터 편집│
              │ 해석문 편집 │해석문 편집 │
              │ 재조회 버튼 │재조회 버튼 │
              └──────────┴──────────┘
                        │
              [재조회 버튼 클릭]
                        │
                        ▼
                  handleRerun()
                        │
                  ├── 처리 과정 5단계 (각 800ms)
                  └── 재조회 결과 스트리밍 출력
```
