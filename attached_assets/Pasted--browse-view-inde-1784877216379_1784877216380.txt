# 브라우즈 화면 — "내가 만든 모든 비서" · "공개전 테스트 요청 비서" 탭 구성

비서 목록 화면(`#browse-view`)의 두 탭 구성입니다.

- 마크업: [index.html:114-159](../web/index.html#L114-L159)
- 렌더링: `renderBrowse()` → `renderMineGrid()` — [app.js:1613-1657](../web/app.js#L1613-L1657)
- 카드: `renderCard(a)` — [app.js:2290-2442](../web/app.js#L2290-L2442)

> **핵심 구조**: 두 탭은 별도 DOM이 아니라 **하나의 그리드(`#card-grid`)를 공유**합니다.
> `state.browseTab`(`"mine"` / `"test"`) 값에 따라 필터·안내문·빈 상태만 달라지고,
> 카드 마크업과 액션 버튼은 완전히 동일합니다.

## 1. 탭 ①  내가 만든 모든 비서 (`browseTab = "mine"`)

내가 만든 **모든 비서**를 보여주는 기본 탭입니다.

### 대상 필터
- 필터 없음 — 본인 작성 비서 전체 표시 (PoC에서는 모두 본인 소유로 간주) — `filteredAssistants()` [app.js:1541-1542](../web/app.js#L1541-L1542)
- 검색어가 있으면 이름·설명에 대해 추가 필터

### 안내 배너
- 없음 (test 탭과 달리 상단 인트로 배너 없음)

### 빈 상태 — [app.js:1640-1641](../web/app.js#L1640-L1641)
```
아직 만든 비서가 없습니다.
위의 + 나만의 비서 만들기로 시작해 보세요.
```

## 2. 탭 ②  공개전 테스트 요청 비서 (`browseTab = "test"`)

다른 사람이 **공개 전 테스트를 요청한 비서**(관리자가 `public_test=true`로 지정)를 함께 테스트·평가하는 탭입니다.

### 대상 필터
- `a.public_test === true` 인 비서만 — `filteredAssistants()` [app.js:1543-1545](../web/app.js#L1543-L1545)
- `public_test`는 **서버(관리자)에서 지정** → 프런트엔드에 "테스트 요청" 버튼은 없음
- 검색어가 있으면 이름·설명에 대해 추가 필터

### 안내 배너 (상단 인트로) — [app.js:1646-1652](../web/app.js#L1646-L1652)
```
다른 사람이 공개 전 테스트를 요청한 비서입니다.
함께 사용해 보고 평가·코멘트를 남겨 주세요.
```
- 카드 목록 위에 `.tab-intro` div로 표시 (mine 탭에는 없음)

### 빈 상태 — [app.js:1637-1638](../web/app.js#L1637-L1638)
```
아직 공개전 테스트를 요청한 비서가 없습니다.
다른 사람이 공개 전 테스트를 요청하면 이 탭에서 함께 테스트·평가할 수 있습니다.
```

### 이 탭 카드의 특징
- 각 카드에 **`공개전 테스트` 배지** 표시 (`a.public_test`) — [app.js:2370-2374](../web/app.js#L2370-L2374)
- `승인 대기(official_pending)` 상태여도 `public_test` 비서는 **잠기지 않고 사용 가능** (테스트 목적) — [app.js:1253-1255](../web/app.js#L1253-L1255)
