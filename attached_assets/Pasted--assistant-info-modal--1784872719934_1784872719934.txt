# 비서 상세 모달 (`#assistant-info-modal`) 구성

스토어/마켓에서 **비서 카드를 클릭**하면 열리는 상세 정보 모달의 구성 내용입니다.
(예: "연예상담 비서" 카드를 눌렀을 때 뜨는 창)

- 마크업: [index.html:536-595](../web/index.html#L536-L595)
- 채우는 로직: `openAssistantInfoModal(a)` — [app.js:1954-2125](../web/app.js#L1954-L2125)
- 카드 클릭 → 모달 열기: [app.js:1864](../web/app.js#L1864), [app.js:1901](../web/app.js#L1901), [app.js:1945](../web/app.js#L1945)

## 구성 요소 상세

### 1. 헤더 (아이콘 · 이름 · 메타)

| 요소 | 표시 예시 | 데이터 바인딩 | 위치 |
|---|---|---|---|
| 닫기 버튼 | `×` | `data-dismiss="info-modal"` | [index.html:539](../web/index.html#L539) |
| 아이콘 이미지 | (업로드 이미지) | `a.icon_image` | [app.js:1958-1961](../web/app.js#L1958-L1961) |
| 아이콘 이니셜 | `연` | `a.icon` 또는 이름 첫 글자 | [app.js:1965](../web/app.js#L1965) |
| 이름 | `연예상담 비서` | `a.name` | [app.js:1968](../web/app.js#L1968) |
| 작성자 | `작성자: 나` | `a.author \|\| "나"` | [app.js:1969](../web/app.js#L1969) |
| 구분점 `·` | 카테고리 있을 때만 표시 | — | [app.js:1975](../web/app.js#L1975) |
| 카테고리 | `카테고리: {이름}` | `categoryName(a.category)` | [app.js:1971-1974](../web/app.js#L1971-L1974) |

### 2. 배지 (`#info-badges`)

조건에 따라 배지를 조합해서 표시합니다. — [app.js:1981-2010](../web/app.js#L1981-L2010)

| 배지 | 클래스 | 조건 |
|---|---|---|
| `v1` (버전) | `badge version` | 초안(`is_draft`)이 아닐 때 |
| `공식` | `badge official` | `a.is_official` |
| `승인완료` | `badge approved` | 공식 + `official_pending` 아님 |
| `버전 갱신중` | `badge updating` | 공식 + `official_pending` |
| **`승인 대기`** | `badge pending` | 공식 아님 + `official_pending` |

> 예시의 "연예상담 비서"는 `승인 대기` 상태 → 아직 공식 승인 전이므로 `승인 대기` 배지 표시.

### 3. 설명

- `#info-description` ← `a.description` — [app.js:2017](../web/app.js#L2017)

### 4. 통계 4칸 (`.info-stats`)

| 칸 | 값 예시 | 라벨 | 데이터 바인딩 |
|---|---|---|---|
| 평가 | `★ -` (평가 없으면 `-`, 있으면 `★ 4.5`) | `평가 (0)` | `a.rating`, `a.rating_count` — [app.js:2022-2023](../web/app.js#L2022-L2023) |
| 카테고리 | `-` | `카테고리` | `catName` — [app.js:2024](../web/app.js#L2024) |
| 대화수 | `0` | `대화수` | `a.dialogue_count` — [app.js:2025](../web/app.js#L2025) |
| 메시지수 | `0` | `메시지수` | `a.message_count` — [app.js:2026](../web/app.js#L2026) |

> 숫자는 `formatCompact()`로 축약 표기(예: 1.2천).

### 5. 대화 스타터 (`#info-starters-wrap`)

- 스타터가 있을 때만 노출 — [app.js:2102-2122](../web/app.js#L2102-L2122)
- `a.conversation_starters` 배열의 각 문구를 버튼으로 렌더
- **버튼 클릭 시**: 모달 닫기 → `enterAssistantMode(a)` (채팅 진입) → 입력창에 해당 문구 자동 입력
- 예시:
  - 최근에 본 영화 중 가장 인상 깊었던 작품은 무엇인가요?
  - 가장 좋아하는 가수와 그 이유를 알려 주세요.
  - 연예계 최신 스캔들에 대해 알려 주세요.
  - 추천하고 싶은 드라마가 있나요?

### 6. 평가 (평점 막대) (`#info-ratings`)

- 5점 → 1점 순으로 각 점수의 비율을 막대로 표시 — [app.js:2028-2060](../web/app.js#L2028-L2060)
- 데이터: `a.rating_distribution` (각 점수별 개수)
- 평가가 하나도 없으면 → **"아직 평가가 없습니다."** 안내 표시 ([index.html:580](../web/index.html#L580))

### 7. 코멘트 (`#info-comments-wrap`)

- 코멘트가 있을 때만 노출 — [app.js:2062-2086](../web/app.js#L2062-L2086)
- `a.comments`를 **최신순**(`ts` 내림차순)으로 정렬
- 각 항목: 코멘트 텍스트 + 작성 시각(`toLocaleString("ko-KR")`)

### 8. 같은 작성자의 다른 비서 (`#info-others-wrap`)

- 같은 작성자의 다른 비서가 있을 때만 노출 — [app.js:2088-2100](../web/app.js#L2088-L2100)
- 필터 조건: `id`가 다르고 · 초안이 아니며 · 작성자가 같은 비서
- **최대 8개**까지 표시
- 각 카드: `renderOtherCard(o)` — [app.js:2227-2261](../web/app.js#L2227-L2261)
  - 아이콘(`.o-icon`) · 이름(`.o-name`) · 설명(`.o-desc`)
  - **카드 클릭 시**: 클릭한 비서로 모달 내용을 교체(모달 안에서 전환)
- 예시: 영화추천 비서 / 여행추천비서 / 수학알고리즘추천비서 / 카드리미 / 노트북 추천 비서 / 사규 답변 비서 / 이메일 도우미 / 비밀번호규정

### 9. 하단 버튼 — 💬 채팅 시작 (`#info-start-chat`)

- 클릭 시 `enterAssistantMode(a)` 실행 → 해당 비서와 채팅 시작 — [app.js:3271-3275](../web/app.js#L3271-L3275)
- **잠금 처리**: `승인 대기` / `버전 갱신중` 상태(`isChatLocked(a)`)면 버튼 비활성화 + 안내 툴팁 — [app.js:2012-2015](../web/app.js#L2012-L2015)

## 닫기 동작

- 배경(`.modal-backdrop`) 클릭 또는 `×` 버튼 → `closeAssistantInfoModal()` — [app.js:3276-3278](../web/app.js#L3276-L3278)

## 조건부 노출 요약

| 섹션 | 노출 조건 |
|---|---|
| 카테고리 · 구분점 | 카테고리 값이 있을 때 |
| 대화 스타터 | 스타터가 1개 이상일 때 |
| 평가 막대 | 평점 분포 합계 > 0 (없으면 "아직 평가가 없습니다.") |
| 코멘트 | 코멘트가 1개 이상일 때 |
| 같은 작성자의 다른 비서 | 조건을 만족하는 다른 비서가 있을 때 |
| 💬 채팅 시작 (활성) | `승인 대기`/`버전 갱신중`이 아닐 때 |
